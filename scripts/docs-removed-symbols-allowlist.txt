# baseline at all, are documented in scripts/check_docs_symbols.harn.

# Entry forms, one per line; `#` starts a comment:
#
#   page <path>       every removed-API mention on that page is fine
#   <path> <symbol>   that one symbol on that one page is fine

# entry goes stale — when the page stops mentioning the symbol, or when the
# compiler stops calling the symbol removed — so a fixed page forces the
# line to be deleted rather than leaving a permanent exemption behind.
# Deleting a line needs no ceremony. Adding one is a reviewed act.
