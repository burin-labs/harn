`HARN-OWN-004` listed a shape type annotation alongside `schema_expect()` and
`schema_is()` without saying that it is the one remedy checked only statically:
an annotated `json_parse` result still accepts a wrongly-typed field, and still
accepts a JSON array where a record was declared. The help and the diagnostic
page now say so and offer `schema_check()` as well, so an author choosing the
cheapest fix knows what it does and does not buy. Whether an annotation should
clear the rule at all is still open.
