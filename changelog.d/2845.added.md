- Added the `harn-rules` embedded skill and a "Rule engine cookbook" (Rule Engine Epic B). The skill
  (`harn skills get harn-rules`) is the agent-facing reference for authoring and running structural rules — matcher
  forms, typed placeholders, `where`/`transform`/`fix`, safety tiers, and the `harn scan` / `harn codemod` /
  `std/rules` surfaces. The cookbook (`docs/src/cookbooks/rules-engine.md`) is the worked-example how-to: search for a
  code shape, write a reusable rule, apply a codemod (dry-run by default), and run a rule from `.harn`.
