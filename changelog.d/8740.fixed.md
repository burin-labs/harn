A confined `git` can now read the paths its global configuration names. The
sandbox grants read access to the global config file and to every
`core.hooksPath`, `core.excludesFile`, `core.attributesFile`, `include.path`,
`includeIf.*.path`, and absolute credential helper it names, so `git commit`
no longer fails for a user whose global hooks live outside the workspace.
Those paths stay read-only: a confined child cannot write into them.
