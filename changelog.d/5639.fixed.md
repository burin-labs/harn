- Stopped the `harn-cli` build script from marking itself dirty on every Cargo
  invocation on Windows. It handed `cargo:rerun-if-changed` a canonicalized
  path, which on Windows is a `\\?\` verbatim path that Cargo cannot match
  against the ordinary path in its fingerprint, so the crate read as changed
  every time and rebuilt in full — a measured ~2m12s tax on every Cargo call,
  for every job and every developer. Cargo is now told the plain package-relative
  path; canonicalizing remains, but only inside the check that the payload has
  not escaped the package.
