- **Replay and eval verdicts never compare a run with itself (#10955).**
  `harn replay`, `harn eval`, eval suites, eval packs and the `run_record_eval`
  builtins check a run only against the replay fixture it recorded, and fail a
  verdict that compared nothing. A run record with no recorded fixture now
  fails instead of passing against one derived from itself. Replay traces get
  the replay oracle's verdict on both recorded executions. Session replay
  reports `rebuilt, not checked`. Files whose `_type` is not `run_record` are
  refused.

  Migration: Rust consumers constructing `ReplayEvalReport` must set
  `expectations_compared`, and those constructing `ReplayOracleReport` must
  set `compared_values`; use `0` when nothing was compared, or spread
  `..Default::default()`. Run records written by hand need `_type:
  "run_record"` and a `replay_fixture` that records at least one expectation.
  Records Harn saves already carry both.
