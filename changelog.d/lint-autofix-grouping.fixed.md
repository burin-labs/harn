Lint autofixes no longer write unparseable or wrong code around parentheses: a grouped expression's span now covers its parentheses, so `let-then-return`, `constant-logical-operand`, `nil-coalesce-*`, and `redundant-clone` keep `(a + b) * c` intact; `redundant-nil-ternary` groups a looser fallback as `x ?? (a || b)`; `legacy-doc-comment` leaves a trailing `// comment` on a code line alone instead of replacing that line; and `empty-block` no longer deletes a block whose condition pipes into a call. `indent` also skips whitespace-only and CRLF-blank lines, and `harn` reports a non-UTF-8 argument instead of panicking.
