- **User-test work counters (#7859).** User-test JSON receipts and test-worker
  run responses use schema v5 and include per-case `work.vm_steps`, a counted
  bytecode instruction total shared across child VMs. Cases that never
  construct a VM report `work: null`; native builtin internals aren't counted.

  Migration: accept schema v5 and read `work.vm_steps` only when `work` isn't
  null. Replace existing v4 timing baselines with v5 receipts generated by
  `harn test --json-out`.
  Rust producers upgrading the receipt contract to v5 should replace
  `harn_test_runner::TestResult` literals with
  `TestResult::unmeasured(name, file, passed, duration_ms)` and set diagnostics
  on the returned result. This constructor initializes unavailable measurements
  without requiring producers to enumerate every receipt field. Instrumented
  producers must set `work = Some(Box::new(recorder.snapshot()))` after the
  VM execution tree stops. Do not represent unavailable work as measured zero.
