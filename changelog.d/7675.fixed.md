- Process tool results now report inline output truncation instead of leaving it
  to be inferred. `run_command`, `run_test`, `run_build_command`,
  `manage_packages`, and the background progress and terminal payloads carry
  `stdout_truncated` / `stderr_truncated`, the true per-stream `stdout_bytes` /
  `stderr_bytes`, and a `truncation_notice` sentence naming what was kept and
  what was omitted. Previously a capture over `max_inline_bytes` returned a
  prefix with `exit_code: 0` and no marker, so the first N entries of a sorted
  enumeration read as a complete answer about a smaller world.
