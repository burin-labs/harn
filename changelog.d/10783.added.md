- **Run tapes record a whole run, and a branch can replay its prefix (#10783).** With
  `recording: full` and a workspace, a run records every model call, agent tool
  dispatch result, file effect, prompt render, runtime-store seed, and clock, random,
  env and cache read. A branch serves the first K model calls and every tool dispatch
  and recorded read inside them from the tape. It checks each whole request against
  its recorded digest, refuses any other effect (process exec, HTTP, MCP, permission
  prompts, hooks, native decisions, file writes), keeps runtime-store writes in
  memory until the branch goes live, and fails closed with a named divergence on the first mismatch, refusal or
  under-run. Served model calls keep their recorded usage, flagged `branch_served`,
  and cost nothing; under a mock script each served call consumes its response.
