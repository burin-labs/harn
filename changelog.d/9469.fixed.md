- **code_index refactors refuse input that does not parse (#9469).**
  `rename_symbol` and `change_signature` now run one shared parse gate on
  every file they would rewrite, before planning, and return `syntax_error`
  with every file byte-identical. The gate also refuses constructs a
  language rejects although its tree-sitter grammar accepts them: Python 2
  `print` and `exec` statements in Python files, which a signature change
  previously rewrote. A file that only mentions the name in a comment is not
  gated.
