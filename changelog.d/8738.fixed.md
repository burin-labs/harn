On Windows the command tool's children are now confined. They used to be launched through a `Command`, which cannot
carry a sandbox, so they ran unconfined. Every confined Windows child now runs under a write-restricted copy of the
caller's token instead of an AppContainer: `cmd`, `git` and PowerShell start where the AppContainer failed them, and a
write succeeds only in the policy's writable roots. Reads and network are not confined on Windows. The write grant is
made once per policy and reused by every later spawn.
