- The agent loop now projects its remaining call budget before each turn spends
  anything, emitting a `harn.agent_loop_call_budget_projection.v1` receipt
  instead of discovering exhaustion once useful work can no longer be completed.
  A measured zero is kept distinguishable from an unavailable measurement, so an
  unmeasured loop no longer reads as exhausted.
- The calls held back for verification, recovery, and terminal reporting now come
  from one owner rather than a single verification-only reserve, and a run
  blocked by the host-side pre-call budget gate is attributed as
  `pre_call_budget_block` instead of stopping unattributed.
