- **Turn-stable host reads are memoized per agent-loop iteration (#5190).** Context assembly re-fetched
  `runtime.pipeline_input` (and a few sibling read-only runtime/session facts) from the host on every shard —
  ~20 identical round-trips per turn. The dispatch boundary now serves these from a per-turn memo that clears at
  each `iteration_start`, so the host is hit once per turn while values that legitimately change between turns
  (e.g. a mid-session model switch) are still observed. No call site changes.
