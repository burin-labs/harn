Workflow-assigned `HARN_*` environment names are now held to the environment
registry. Censuses already covered compiled Rust and `.harn` scripts, but a
workflow was neither, so one could assign a name in the reserved namespace and
ship a job that exits with `HARN-ENV-001` the first time it starts a Harn
process. `bump-harn.yml` had done exactly that with
`HARN_BUMP_APPLY_BEHAVIOR_PRESERVING_FIXES`, which failed every bump run at
startup. A third census over `.github/workflows/**` reads the assigning forms, a
YAML mapping key and a shell `export`, and found nine unregistered names across
four workflows; all are now registered.
