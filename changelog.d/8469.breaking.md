- **Completed calls report provider-confirmed reasoning effort (#8469).**
  `effective_reasoning_effort` explicitly reports `not_reported` when the
  provider supplies no usable echo. Responses API echoes distinguish operator
  selections, catalog defaults, reasoning policy, provider defaults, and
  provider adjustments.

  Migration: Rust consumers that construct `ProviderTelemetry` or `LlmMock`
  with exhaustive struct literals must initialize `effective_reasoning_effort`
  to `EffectiveReasoningEffort::NotReported` when no provider observation exists.
  `ProviderTelemetry` literals can instead fill omitted fields with
  `..Default::default()`. Harn scripts that construct a `LlmResponse` record
  must add `effective_reasoning_effort: {status: "not_reported"}` when no
  provider observation exists. Existing recordings remain readable.
