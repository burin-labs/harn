- **Run Harn child interpreters across runtime worker threads (#7101).**
  `spawn`, all `parallel` forms, and `pool.submit` now share one subtask
  boundary that carries session, event-log, security, redaction, egress,
  budget, and pool context across worker threads. Set
  `HARN_VM_SUBTASK_PLACEMENT=current_thread` for an embedding host that must
  retain pinned scheduling. Inactive CLI interrupt handles also stay off the
  interpreter's per-instruction slow path, eliminating the shared-mutex
  contention that previously made CPU-bound pool fan-out slower than serial
  execution.
