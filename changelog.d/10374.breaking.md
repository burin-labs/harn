- **Java method references and rename (#10374).** Call lookup and method rename
  use explicit receiver types to keep unrelated methods with the same name
  separate. Rename accepts qualified names and exact declaration positions,
  and refuses unsupported receiver bindings before writing.

  Rust callers constructing `harn_hostlib::code_index::Node`
  must now provide `col: Option<u32>` and `owner_type: Option<String>`.

  Migration: add `col: None` and `owner_type: None` to existing `Node` struct
  literals when those facts are unknown. When known, use the measured 1-based
  UTF-16 identifier column and the actual fully qualified Java declaration or
  receiver type. Keep an unknown column as `None`; don't substitute column 1.
