- **A tool handler's plain-dict refusal is now classified a failure (#7884).**
  A handler that returned `{ok: false}`, `{success: false}`, `{status: "error"}`
  or `{isError: true}` as an ordinary dict had that declaration replaced by a
  display rendering before anything read it, so the dispatch envelope, the
  receipt, and the model all saw a success. Only a handler that raised was
  recorded as failing. Boolean `ok` or `success` now keeps the return
  structured whether it came from a typed struct or a plain dict.
