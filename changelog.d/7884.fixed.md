- **A tool handler's plain-dict refusal is now classified a failure (#7884).**
  A handler that returned `{ok: false}`, `{success: false}` or
  `{isError: true}` as an ordinary dict had that declaration replaced by a
  display rendering before anything read it, so the dispatch envelope, the
  receipt, and the model all saw a success. Only a handler that raised was
  recorded as failing. The declared outcome now travels beside the rendered
  text rather than instead of it, so the transcript string and its token cost
  are unchanged.
