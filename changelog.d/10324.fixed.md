Run Gradle builds and tests under loopback-only process confinement on Linux and macOS. The Linux namespace helper keeps
the caller's uid, so the JVM finds the caller's `~/.gradle`, and binds the session temp dir over the child's `/tmp`, so
the JVM attach socket and Gradle's native libraries land inside the session. On macOS the session temp alias is short
enough to hold a Unix socket, sockets there no longer need a separate grant, and the loopback grant sets
`-Djava.net.preferIPv6Addresses=true` so env-less Gradle workers reach the daemon.
