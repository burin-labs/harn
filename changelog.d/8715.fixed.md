- The runtime bump driver no longer leaves a repin pull request armed on an
  already-mergeable head, where GitHub never fires the merge. After arming it
  reads the pull request back: a clean pull request is enqueued under its head
  when the base branch has a merge queue and merged under its head otherwise,
  and a pending one stays armed. GitHub's refusal to arm a clean pull request
  now lands it instead of failing the run. A moved head is refused. The
  outcome is written to the receipt's `auto_merge.state` and the `landing`
  output, and a repin that did not land fails the run.
