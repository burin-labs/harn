- **Append-only reminder placement keeps the provider prompt prefix cacheable
  (#6850).** Default placement re-derives the context-directive envelope on
  every request and folds it into the trailing `user` turn, so the turn that
  carried it is rewritten once the conversation grows past it — which
  invalidates the prompt prefix on every provider that caches one. Opting in
  with `reminders: {append_only: true}` (or `HARN_REMINDERS_APPEND_ONLY=1`)
  commits the envelope into durable history at the turn boundary that emits it,
  so request N+1 begins with request N: directive content is unchanged,
  deduplication becomes "do not re-issue" rather than an edit to history, and
  compaction remains the one deliberate prefix break. Off by default, because
  placement is model-visible.
