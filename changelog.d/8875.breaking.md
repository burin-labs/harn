- **Custom bump adapters require repair preservation (#8875).**
  `std/bump/runtime` calls `preserve_repairs` before validation. The live
  adapter supplies it.

  Migration: add `preserve_repairs(existing, base)` to custom `BumpAdapter`
  implementations and return a `BumpRepairs` record. Replay existing repairs
  onto the refreshed files; return `ok: false` with conflict paths if replay
  fails. An adapter with no open pull request returns
  `{ok: true, commits: [], conflicts: [], detail: "no open bump PR"}`.
