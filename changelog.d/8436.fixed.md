- **AWS Smithy types now resolve across the whole compatible range (#8436).**
  The published `cloud-aws` feature bounded Smithy types to one exact release,
  which blocked patch fixes and desynchronized from the package-verify minimum
  whenever a dependency update rewrote it. The bound is now the range the
  constraint actually describes: 1.6.3 or later, below 1.7. The floor moved off
  1.6.2 because `aws-config` requires `^1.6.3` itself, so no fresh AWS graph
  could resolve the old one.
