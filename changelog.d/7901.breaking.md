Tool handlers now reject freeform dictionary results at dispatch, including dictionaries returned through helpers or
mutable bindings. The text-and-data envelope is now `harn.agent_tool_handler_result.v2`; its data fields no longer
decide whether the operation succeeded.

Migration: return a nominal struct with one boolean `ok` or `success` field, or use
`agent_tool_handler_result(text, data, outcome)` with `outcome` set to `"ok"` (the default), `"error"`, or `"rejected"`.
Replace v1 envelopes with this helper and declare failure or refusal through `outcome` instead of data keys.
