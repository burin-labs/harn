- Caller `cache_control` markers now defer Harn's prompt-cache breakpoint by where they sit, not by key name. A marker
  on a message, a content block, a tool-result block, or a tool definition defers it on every route, including
  Anthropic tool definitions. A key named `cache_control` inside tool arguments or a JSON schema no longer suppresses
  the breakpoint on OpenAI-compatible routes.
