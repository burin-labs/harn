- The command-policy scan now reads `git push` from its parsed arguments. Forced
  refspecs (`+main`), `--mirror`, and pushes behind `git -C <dir>` hit the
  never-approvable force-push floor, and remote ref deletions (`:main`,
  `--delete`, `--prune`) now carry the `git_force_push` label. A branch name
  that merely contains `-f` is no longer labelled (#8930).
