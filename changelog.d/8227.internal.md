Protocol artifacts no longer stamp the workspace crate version. `artifactVersion`
and `HARN_PROTOCOL_ARTIFACT_VERSION` are gone from the manifest, the round-trip
fixture, and the TypeScript, Swift, Rust, Python, and Go bindings; the manifest's
`schemaVersion` remains the field consumers compare. A development or release
version bump now leaves every generated artifact byte-identical, so the
committed-artifacts check no longer goes red on main after a bump. The
`dump-protocol-artifacts --artifact-version` flag is removed with the stamp it
fed, and `harn doctor` checks artifact drift by comparing the manifest this
binary would write against the checked-in bytes instead of comparing versions.
