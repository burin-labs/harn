The code index restores its symbol graph from a shared, immutable generation
built in a few linear passes, with edits kept in a small copy-on-write delta
that is periodically folded back in. Restarts are faster, a restored index uses
about 30% less memory, and branch overlays share the base graph instead of
copying it. Graph nodes are stored in snapshot sections that decode in
parallel, so the first start after upgrading rebuilds the index once.
