A module that imports an `enum` can now construct and `match` that enum's variants at runtime, instead of throwing
"Undefined variable" while `check` passed. The compiler previously seeded its enum catalog only from a module's own
declarations, so an imported enum was unknown and `ImportedEnum.Variant(...)` construction and match arms lowered to a
bare variable load. The compiler now accepts the same resolved imported type declarations the type-checker already
uses (`Compiler::with_imported_type_decls`), and the run/test/bench entry points seed it from the module import graph
they build once for the checker, keeping check-time and run-time resolution aligned.
