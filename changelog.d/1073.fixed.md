`harn package verify` now inventories package tests with the runtime's real parser
and fails when a selected test file contains no `test_*` or `@test` pipeline. Its
compact schema-v3 receipt records selected and discovered counts plus the identities
of files with no tests or parse errors, while intentionally empty packages require a
reasoned `[tests].allow_empty` manifest declaration. A new `harn package
test-inventory` reports the same discovery for one package without executing tests
or changing any file, so a fleet can find packages whose tests run nothing before a
release reaches them. Runtime bump pull requests retain the exact pre-mutation
discovery receipt for repair.
