- **The agent shell guard no longer refuses `git -C <dir> ... | grep "a\|b"` as a stash write (#10790).**
  Any backslash in a command made the guard distrust that `git show` is a builtin, and
  with `-C` the unreadable alias lookup then refused it. A backslash now counts only
  inside an assignment name or a `$` expansion name. Real stash writes, `PATH=` changes
  and escaped assignment names stay refused.
