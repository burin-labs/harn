Machine spend ledgers upgrade to schema version 3 for session budget audit
receipts. Existing reservations and approval history are preserved. Older Harn
versions refuse the upgraded ledger.
Rust hosts using struct literals must supply the new optional
`AcpServerConfig::machine_spend_quota` and `AcpPromptFailureFacts::machine_spend`
fields; constructor and default-based callers inherit their defaults.
