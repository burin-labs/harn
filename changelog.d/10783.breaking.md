- **Run tapes move to format version 2, and two prompt builtins are removed (#10783).**
  `TapeRecordKind::LlmCall` gains `call_index`, `request`, `messages` and
  `attribution`. The new `ToolCall`, `PromptRender` and `CacheLookup` kinds record
  tool results, prompt renders and cache or runtime-store reads.
  `render_prompt` now always records provenance, so `render_with_provenance` and
  `prompt_mark_rendered` are gone.

  Migration: Rust code that matches `TapeRecordKind::LlmCall { request_digest,
  response }` should match `LlmCall { request_digest, response, .. }`, and a
  match over `TapeRecordKind` needs arms or a wildcard for `ToolCall`,
  `PromptRender` and `CacheLookup`. Request digests are unchanged, so version 1
  tapes still compare. Scripts that called `render_with_provenance(path, bindings)`
  call `render_prompt(path, bindings)`; drop any `prompt_mark_rendered(id)` call.
