- **The completion judge is shown a passing background verifier (#7895).**
  `poll_command` and `wait_command` now declare `completion_evidence_role:
  "verification"`, so a test run finished under a background handle occupies
  the judge's verification slot. Previously these tools carried no declared
  role and fell through to `other`, which fills no slot, so a run whose only
  verifier ran in the background reached the judge with no verification
  evidence at all.
