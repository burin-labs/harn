Self-hosted llama.cpp Qwen3.6 routes now serve provider-native tool calling.
The capability row previously said the native channel does not return parseable
tool calls on this route, and that verdict also acted as a steer: an explicit
`tool_format = "native"` was silently rewritten to the fenced-JSON text
contract, so the native channel could not be reached at all.

A 36-run forced-format receipt on CUDA hardware (six coding-agent fixtures, two
replicates, three channels, no skipped runs) measured native returning parseable
tool calls on every measurable cell, matching an earlier Apple Silicon receipt
exactly. Native and the tagged text contract tie on completion at 10 of 12, and
fenced JSON trails at 8 of 12.

The resolved default is unchanged: `preferred_tool_format` stays `json`, so this
only means an explicit native pin is now honored instead of rewritten. Moving
the default is a separate decision on separate evidence, since the receipt makes
no claim of a native completion advantage.
