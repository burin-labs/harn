**The feature matrix says where Harn is the wrong choice.** Six rows join the
table on which Harn rates Partial or No: calling it from an existing codebase,
reusing your language's libraries, managed hosting, production maturity,
integration breadth, and futures that outlive their scope. A comparison in
which the publisher wins every row is an advertisement, and a test now fails if
the rows marked as favouring other systems stop matching the rows Harn
actually loses.

**Docs style: use contractions.** The `harn-docs` writing contract now names
the Google developer documentation style guide as the reference for questions
Slopwash doesn't cover, and asks for common contractions — negations
especially, since a reader scanning a page skips over "not" but can't misread
"don't".
