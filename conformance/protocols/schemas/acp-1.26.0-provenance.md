# ACP stable schema reference

`acp-1.26.0-upstream.schema.json` is the unmodified stable schema from
[agent-client-protocol tag schema-v1.26.0](https://github.com/agentclientprotocol/agent-client-protocol/blob/schema-v1.26.0/schema/v1/schema.json).
Its SHA-256 is `4bcd1d2051ff7ed379bd9b234fb9b09c5ab9245478698e9fab805bd9b52a33a6`.
Protocol checks use its original definitions and reference graph, independently
of the Harn adapter profile. Update this reference from the upstream source;
do not repair a failing payload by changing the reference schema.
