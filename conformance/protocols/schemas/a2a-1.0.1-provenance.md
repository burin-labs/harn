# A2A 1.0.1 schema snapshot

`a2a-1.0.1.schema.json` contains JSON shape schemas generated from the
[upstream protobuf contract](https://github.com/a2aproject/A2A/blob/3303592588e388e62e0f69f701af531d2f4e3991/specification/a2a.proto).
The source is tag `v1.0.1`, commit `3303592588e388e62e0f69f701af531d2f4e3991`,
with SHA-256 `e195bf96ab630c69797851970203e1b2b6b19528f2e9803b7d904b91a5104016`.

Generation used protoc 29.3 and `bufbuild/protoschema-plugins` v0.6.0,
`--jsonschema_opt=target=json`. Google API annotation imports came from
`googleapis/googleapis` commit `646596e286b464ca2c2cca6f4c767e7c19046489`.
Every generated JSON file became a `$defs` entry keyed by its filename. Its
`$id` was removed and each file reference was replaced by the corresponding
local `$defs` reference. No validation rules were added or removed.

The protobuf contract is normative. These generated schemas check JSON shapes
but do not enforce every required-field annotation or protobuf oneof rule.
The server regression also asserts dispatch, lifecycle state, required fields,
response unions, and refusal before task allocation.
